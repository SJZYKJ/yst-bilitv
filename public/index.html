黑名单

-
IP 拉黑：这个网络发来的请求一律被挡。
设备拉黑：按 APP 上报的 MAC / 设备标识挡，换 IP、换宽带、换网络都还是挡，也不允许再自助授权。
未授权超额自动封禁 -
未授权设备成功请求累计满 次 → 自动拉黑
只统计未授权设备的成功请求（2xx / 3xx）：被门禁挡掉的、被限流挡掉的都不算，已授权设备完全不参与计数。
封禁时把它的 MAC / 设备标识一起拉黑，换网络也挡；选「设备 + 当前 IP」还会连它当时的网络 IP 一起封。
如果那个 IP 上还有已授权的设备（同一个网络），就只封设备、不封 IP，免得把你自己的盒子一起挡了。
手动把设备移出黑名单后，计数从 0 重新开始。

账号使用方式

-

决定中转要不要拿池子里的会员账号去换高清。盒子界面上是否显示会员号，由这里决定。

纯游客：请求里不带任何账号，零封号风险，画质上限 480P。
隐藏身份：用账号换高清，但盒子问"我是谁"时一律回答未登录，界面上不出现会员号。
直接用账号：原样注入，画质最好，但盒子会员中心会显示账号昵称，多设备共用有风控风险。

播放画质

-

盒子点开播放时，中转向 B站 请求的清晰度档位。改完立即生效，盒子下次播放就按新档位取流，不用重装 APP。

4K 优先：一律向 B站 要最高档，片源有 4K 就给 4K，没有就自动给它的最高档（4K 和 1080P+ 需要账号有大会员）。
最高 1080P：封顶 1080P，省带宽、起播更快，普通登录账号就够。
跟随盒子设置：中转不改档位，盒子自己选什么就取什么。

开启后，待授权设备也能正常加载首页、推荐、分区、搜索和封面 —— 只是点播放时仍然拦，会弹授权页。
